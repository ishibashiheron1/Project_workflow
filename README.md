# Marine Mammal Acoustic Classification Project

This repository contains my development work for the FAU Engineering Design II marine mammal acoustic classification project.

## Project Goal

The goal of this project is to develop a machine learning system capable of identifying marine mammal species from underwater acoustic recordings.

## Current Work

- NOAA Passive Acoustic Monitoring dataset investigation
- Detection timestamp and raw audio matching
- Audio extraction
- 5-second audio preprocessing
- Spectrogram generation
- Dataset preparation for model training

## NOAA Detection Workflow

Detection CSV → Detection Timestamp → Raw Audio Recording → Audio Extraction → 5-Second Sample → Model Training
